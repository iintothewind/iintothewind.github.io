      Vibe Coding副业分析点评

      Vibe Coding 副业四个月：成本超出收益，要放弃吗？—— 点评

      原文链接

      V2EX：https://www.v2ex.com/t/1228385
      项目地址：https://stocks.matraceai.com/

      原文摘要

      楼主是一名程序员，2026 年 3 月起用业余时间开发了一个 A 股新闻事件分析工具「新闻雷达」——抓取财经新闻，用 AI 分析关联行业和公司，记录事件后市场表现。

      四个月数据：

      • 注册用户 384 人，会员用户 29 人（含赠送）
      • 累计会员收入 1600 元
      • 成本：服务器 4000/年 + DeepSeek Flash 推理约 2000 + 股票数据 API 约 2000
      • 近期 AI 推理费用约 100 元/天，月估 3000

      楼主自省： 用持续开发代替了产品验证，工程越做越完整，功能越来越多，但收入未覆盖成本。目前已停止功能更新，转向用户增长，但不擅长推广。

      现有流量来源： Twitter/X (3.1%)、V2EX (2.9%)、iui.su、Google，其余 90% 来源不可识别。

      点评

      核心问题：缺少最基本的商业验证

      在做一个项目之前，有两个问题必须先搞清楚：

      1. 你做的东西有没有人要？谁付钱？
      2. 付的钱能不能覆盖前期投入？

      这两个问题确认了再做不迟。而楼主显然跳过了这一步——技术已经是最容易的部分，但在投入之前没有做市场调研。

      致命伤：成本结构重度依赖 AI API

      DeepSeek Flash 现在 100 元/天，一个月 3000，而会员收入远达不到这个数。更关键的是：

      连 Anthropic、OpenAI、Google 三家头部都没证明卖 token 能稳定盈利，你先重度依赖上去了，成本能控制？

      如果 AI API 调个价、改个策略，整个成本结构就崩了。小副业把自己的毛利率外包给大模型厂商的定价策略，这是结构性的脆弱。

      产品定位错位：给散户看宏观新闻？

      散户要的是"明天买哪个"，要的是代码、操作建议。你给他"江西上半年 GDP 同比增长 4.0%"，他没兴趣。偏宏观、偏政策的分析对交易决策价值有限，付费意愿自然低。

      替代方案：个人项目就别上正经架构

      如果只是个人项目、不打算正经商业化，那完全可以：

      • 本地机器做服务器
      • 薅 Cloudflare 全家桶、Firebase
      • 底层别重度依赖在线 AI 服务

      但一旦上了 4000/年的服务器 + AI 推理管线，那就不是"玩"了，是认真在做生意。做生意的步骤一个没做，这就是最尴尬的中间态。

      总结

      要么认真做生意——先做市场调研、验证付费假设、算清 LTV 和 CAC；要么当个人玩具——低成本架构、自己用着爽就行。中间态最尴尬，投入了真金白银，却没有得到对应的验证。

      楼主自己说得对——用持续开发代替了产品验证。但问题不只是运营不够，而是产品假设本身可能就不成立。
