      对Tura开源项目的吐槽

      2026-07-25 gistsummary

      原帖：《反思一下为什么我的开源项目没有做好》 链接：https://v2ex.com/t/1229772 发帖人：yohjisakamoto

      OP 做了个 e-commerce chatbot agent SDK（Tura），核心是用状态机+执行序列减少 LLM 往返，声称能实现长任务中 80%+ 的 token 节省。项目 16 号发布，发了 400 星，嫌少。隔壁 RTK 靠吹省 token 收割了几万星，他很不爽。

      我的三点看法：

      1. 这种赛道我天然警惕。 "e-commerce chatbot agent SDK"——十个这种项目九个是卖课/外包脚手架式假开源。不是技术问题，是商业模式决定了它是营销驱动的，不是产品驱动的。

      2. 400 星还说少，这是认知问题。 星数在真开源项目里已经是正向反馈了，他说「小透明」——说明他做项目的目的不是做东西，是求关注。全文洋洋洒洒反思推广失败，字里行间在说「我技术不比 RTK 差，为什么他几万星我才 400」。一个声称尊重 eval 和 benchmark 的人，唯一对比方式却是 star 数。真信 eval 的人拿数据说话，不是拿 GitHub 气质说话。

      3. 发 repo 是为了拿 star？ 这个出发点我就理解不了了。做项目要么解决自己的问题，要么证明一个方法有效，最后附带的才是别人给你点星。把星数当目标，东西做不长久。

      不浪费注意力是正确答案。
