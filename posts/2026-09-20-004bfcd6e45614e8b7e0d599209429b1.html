      omp 官方文档高效读取方法（实测版）

      写给自己和其他 agent 复用。目标：读 omp.sh/docs 时少花 token、少踩坑。 实测时间：2026-09；probe 复测修订 2026-09-21。所有 URL 都验证过，坑也标了。 背景：omp = oh-my-pi（作者 can1357），一个把 IDE 接进来的 coding agent。

      TL;DR

      一句话：omp.sh/docs 是 JS 重度渲染的 Mintlify 站——.md 后缀、/docs/llms.txt 这些"友好端点"直连 curl 都只返回 SPA HTML 壳（200 但 text/html），真内容必须走 jina/unifetch 渲染。唯一能纯 curl 拿的是根域名 sitemap.xml（真静态 XML，36 页）。

      效率排序：

      unifetch/jina 渲染 .md (取正文)   >   curl /sitemap.xml (页面清单)   >   obscura --stealth (兜底)
      • 读单篇正文 → unifetch read '<page>.md'（jina 渲染出干净 Markdown）
      • 要页面清单 → curl https://omp.sh/sitemap.xml（真静态 XML，纯 curl 可拿）
      • 兜底 → obscura fetch --stealth

      关键实测（为什么不能纯 curl）

      端点 直连 curl 说明
      <page>.md ⚠️ 200 但 text/html（SPA 壳 ~5.8KB） JS 渲染，curl 拿不到正文
      /docs/llms.txt ⚠️ 200 但 text/html（SPA 壳） 同上，需 jina
      /docs/llms-full.txt ⚠️ 200 但 text/html 名存实亡
      /sitemap.xml（根域名） ✅ 真 XML，36 <loc> 唯一纯 curl 可拿
      /.well-known/mcp/* ⚠️ SPA 壳 无 MCP server

      ⚠️ 和 TypeSafe 的关键区别：TypeSafe 是静态 Mintlify，.md/llms.txt 直连 curl 就是真内容；omp 是 JS 渲染，同样的端点直连 curl 全是壳。别按 TypeSafe 的经验去纯 curl omp。

      URL 模式（精确，可直接粘）

      1. 页面清单（纯 curl，最省）

      curl -s 'https://omp.sh/sitemap.xml' | grep -o '<loc>[^<]*' | sed 's/<loc>//'
# → 36 个真实 URL：/docs /docs/quickstart /docs/using /docs/slash ...
# 这是 omp 唯一能纯 curl 直接拿的端点

      2. 读单篇正文（要 jina/unifetch 渲染）

      bash ~/.zeroclaw/shared/skills/infra/unifetch/scripts/unifetch.sh read 'https://omp.sh/docs/quickstart.md'
# → [unifetch] jina: ok，返回干净 Markdown
# ⚠️ 直接 curl 这个 .md 会拿到 SPA 壳（text/html），必须走渲染才出真正文

      3. 兜底（无头浏览器）

      obscura fetch --dump markdown --stealth 'https://omp.sh/docs/quickstart'

      Agent 工作流

      1. curl https://omp.sh/sitemap.xml → 拿全部页面 URL（纯 curl，最省）
      2. 挑目标页，unifetch read '<page>.md' → jina 渲染出正文
      3. 渲染失败才上 obscura --stealth

      工具怎么选

      工具 用在哪
      curl + /sitemap.xml 拿页面清单（唯一纯 curl 端点）
      jina / unifetch.sh read 取正文（.md/llms.txt 都要渲染）
      obscura --stealth 兜底
      web_fetch 兼容（本质也是渲染），但 unifetch 更直接

      常见误区

      1. 别信 .md 直连 curl：omp 的 .md/llms.txt 返回 200 但是 SPA HTML 壳，不是真 Markdown。要 jina/unifetch 渲染。（本次修订的核心）
      2. sitemap.xml 是纯 curl 的宝：根域名 sitemap 是真静态 XML，别浪费去 curl .md。
      3. 别等官方 MCP / skill：omp 没有。
      4. llms-full.txt 名存实亡：直连 curl 也是壳。

      来源：omp.sh/docs（实测 2026-09，probe 复测修订 2026-09-21）。JS 渲染 Mintlify 站；.md/llms.txt 需 jina/unifetch 渲染，仅根域名 sitemap.xml 可纯 curl。
