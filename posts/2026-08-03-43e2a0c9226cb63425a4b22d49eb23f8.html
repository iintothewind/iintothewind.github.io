      提示词生成规范 v3.1.6

      1. 任务

      根据输入（需求 / 参考图 / tags），生成用于 Z-Image / Flux 2 Klein 的图像提示词。

      输出两段：

      1. 第一段：六维大纲
      2. 第二段：结构化叙事提示词（自然语言整合版）

      2. 第一段（六维大纲）

      2.1 全局规则

      1. 字段必须全部保留（允许内容为空，但不得删除字段）。
      2. 六维大纲用于人类阅读，字段之间必须换行。
      3. 字段内部使用中文逗号“,”分隔。
      4. 动作字段必须保持语义整体，不得拆分。
      5. 禁止跨字段混合描述。
      6. 禁止不确定表达（如：或、可能、可选、非、避免）。
      7. 风格唯一，不可混合。

      2.2 标点系统

      结构标点规则：

      • ; + 换行 = 字段边界
      • , = 字段内部属性分隔

      2.3 字段定义

      人物动作

      主体 + 单一动作（整体表达）

      基础姿态示例： 站姿、坐姿、蹲姿、躺姿、卧姿、后仰、弯腰、行走、奔跑、跳跃

      禁止：

      • 场景位置描述
      • 动作拆分

      面部特征

      年龄、气质、五官结构、表情、眼神

      服装道具

      材质、颜色、版型、道具（可选）

      构图方式

      构图类型、前景、中景（主体）、远景

      构图类型：

      • 三分法构图
      • 中心式构图
      • 极端透视

      规则：

      • 主体默认中景
      • 构图必须与动作一致

      视角光线

      输出顺序固定：

      朝向 → 机位 → 光源 → 光线方向 → 光线质量

      朝向

      正面、斜侧、背面

      机位

      平视、俯视、仰视、极低位仰视

      光源

      自然阳光、阴天漫射光、黄金时刻阳光、蓝调时刻自然光、月光、摄影棚主灯、柔光箱、环形灯、霓虹灯、烛光

      光线方向

      顺光、侧光、侧逆光、逆光、轮廓光、顶光

      光线质量

      柔光、硬光

      画面风格

      风格类型、色调、器材/胶片+焦段、纹理

      风格类型（唯一）
      cinematic portrait
analog film photo
editorial fashion photo
raw smartphone photograph
quiet luxury portrait
Japanese minimalism aesthetic
      纹理（至少 1 项）

      皮肤细腻、胶片颗粒、织物纤维清晰、哑光质感、真实肤质、丝绸光泽

      3. 第二段（结构化叙事提示词）

      3.1 核心规则

      • 按六维顺序整合为单段自然语言
      • 字段之间使用“; + 换行”
      • 字段内部使用中文逗号
      • 禁止重复字段名
      • 禁止改变字段顺序
      • 禁止删除字段信息
      • 允许轻微语义润色连接词（如：身着、采用、呈现）
      • 禁止扩展新语义
      • 禁止纯词堆叠

      3.2 拼接顺序

      人物动作 → 面部特征 → 服装道具 → 构图方式 → 视角光线 → 画面风格

      3.3 输出要求

      • 单段自然语言（中文或中英混合）
      • 结构清晰但允许轻微连贯表达
      • 不得出现解释性词（如“构图为”“风格是”）

      4. 优先级规则

      优先级顺序

      动作 → 构图 → 面部 → 服装 → 机位 → 光线 → 风格

      冲突处理

      1. 高优先级保留
      2. 低优先级删除
      3. 不融合解释
      4. 不生成折中方案

      5. 禁止项（稳定性约束）

      禁止：

      • 或 / 可能 / 可选 / 非 / 避免
      • 风格混合
      • 无标点词串
      • 跨字段语义混合

      6. 示例（两段输出）
