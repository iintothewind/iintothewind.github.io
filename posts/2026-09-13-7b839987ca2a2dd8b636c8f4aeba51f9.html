      网页读取工具对比报告

      测试页：https://api-docs.deepseek.com/zh-cn/quick_start/pricing/

      （Docusaurus SSR，23 KB HTML，含价格表格 + 脚注）

      日期：2026-07-14 · 环境：本机已装 trafilatura 2.2.0 / readabilityrs 0.1.5 / htmlq 0.5.0 / obscura 0.2.2

      工具一览

      • trafilatura
        • 项目地址：https://github.com/adbar/trafilatura
        • 类型：Python 正文抽取
        • 安装：pip install trafilatura
        • 读网页：trafilatura -u "$URL" --markdown（自带下载）或 curl … | trafilatura --markdown
      • readabilityrs
        • 项目地址：https://github.com/iintothewind/readabilityrs-cli
        • 类型：Rust 正文抽取（Mozilla Readability 移植）
        • 安装：GitHub Release 二进制 / cargo install readabilityrs-cli
        • 读网页：readabilityrs -f markdown page.html（吃文件/stdin，不自带下载，需 curl 管道）
      • htmlq
        • 项目地址：https://github.com/iintothewind/htmlq
        • 类型：Rust CSS 选择器查询（HTML5 容错解析）
        • 安装：GitHub Release 二进制 / cargo install htmlq / brew
        • 读网页：curl … | htmlq -t 'table tr'；-f file.html、-a href 'a' 抽属性
      • obscura
        • 项目地址：https://github.com/h4ckf0r0day/obscura
        • 类型：Rust 无头浏览器（V8 + 自绘，约 30 MB 内存 / ~70 MiB 二进制，内建反检测）
        • 安装：GitHub Release 二进制（本机在 ~/.local/bin/obscura）
        • 读网页：obscura fetch --dump markdown URL；可选 --stealth --wait N --timeout N --selector CSS

      测试表现对比

      • trafilatura（输出 1,357 B）
        • 正文段落：✅
        • 价格表格：❌ 整表丢失，--recall 也救不回；"模型细节"一节为空
        • 脚注 (1)–(4)：✅
        • 导航/页脚噪音：无
        • JS 渲染支持：❌ 仅静态 HTML
        • 结构保真度：好（纯文本页）
      • readabilityrs（输出 2,557 B）
        • 正文段落：✅
        • 价格表格：⚠️ 值全在但被拍平成一大段文字，行列结构丢失
        • 脚注 (1)–(4)：✅
        • 导航/页脚噪音：无
        • JS 渲染支持：❌ 仅静态 HTML
        • 结构保真度：中（表格拍平）
      • htmlq（按需输出，63 个单元格）
        • 正文段落：✅（需选择器）
        • 价格表格：✅ 63 个单元格完整可取，行文本可拼（如 价格…空闲时段 0.02元 0.15元），需自己组装
        • 脚注 (1)–(4)：✅
        • 导航/页脚噪音：无（只取所选节点）
        • JS 渲染支持：❌ 仅静态 HTML
        • 结构保真度：高（按 CSS 精确取）
      • obscura（输出 4,964 B）
        • 正文段落：✅
        • 价格表格：✅ 转成 Markdown 表格，全部数值在位（0.02/0.15/0.04/0.30/1/4.5/2/9.0/4/13.5/8/27.0、并发 2500/500）；rowspan 嵌套处略乱
        • 脚注 (1)–(4)：✅
        • 导航/页脚噪音：有（完整导航、TOC、社交链接、版权行）
        • JS 渲染支持：✅ 真实浏览器执行 JS
        • 结构保真度：中高（Markdown 表格近似） | 适用场景 | 纯文章正文、去噪 | trafilatura 空/短时的本地兜底 | 探结构、抽字段/链接列表 | SPA / 反爬 / 需要完整 DOM 转 Markdown |

      结论

      1. 本测试页的"正确性基准"是价格表格：4 个数值维度中——obscura 和 htmlq 数据完整，readabilityrs 数据全但结构丢失（读起来费劲、机器解析易错），trafilatura 直接丢表，在这类"表格为核心内容"的文档页上表现最差。
      2. trafilatura / readabilityrs / htmlq 都只吃静态 HTML：本页是 Docusaurus SSR，curl 即可拿全；若页面是纯 SPA，三者都会失败，只剩 obscura（或上游 jina/firecrawl）。
      3. obscura 是唯一能执行 JS 的，输出最接近"整页所见"，代价是噪音多、二进制重。对静态文档页它属于"大材小用但结果最全"。
      4. 推荐分工：
        • 纯文章正文 → trafilatura（空则 readabilityrs）
        • 表格/字段抽取 → htmlq（精确、零噪音）或 obscura --dump markdown（省事、带结构）
        • SPA / 反爬 → obscura（配 --stealth）

      复现命令

      URL='https://api-docs.deepseek.com/zh-cn/quick_start/pricing/'
curl -fsSL -L -A 'Mozilla/5.0' "$URL" -o page.html

trafilatura --markdown < page.html                 # 1357 B，表格丢失
readabilityrs -f markdown page.html                # 2557 B，表格拍平
htmlq -f page.html -t 'table tr'                   # 63 单元格，结构可拼
obscura fetch --dump markdown "$URL"               # 4964 B，MD 表格完整
